# ADR 0001: 技术栈与零拷贝路径

- 状态：**待决**（阶段0 GPU 探针完成后填写）
- 日期：待定

## 背景
开发规划 §1.2 列出阶段0决策门必须回答的 5 个问题：

1. 能否在 C# 中通过 `MFCreateDXGIDeviceManager` 把 D3D11 设备挂给 MF H.264 编码器？
2. 能否用 `MFCreateDXGISurfaceBuffer` 把 D3D11 渲染目标纹理零拷贝喂给编码器输入样本？
3. 编码器实际接受的 GPU 输入是否为 NV12；若渲染目标为 BGRA/RGBA，RGB->NV12、sRGB->Rec.709/limited-range 转换能否全程在同一 GPU 完成？
4. 渲染 D3D11 设备与硬件编码器是否绑定同一个 DXGI Adapter LUID，而非跨 GPU 传输？
5. 端到端（8192×4096 -> 1080×1920、3 秒、60FPS、H.264）各阶段耗时与是否 ≥60 输出 FPS？

## 决策分支（探针通过后选定其一）
- [ ] **全程 C#**（三项全通）—— 编码不下沉。
- [ ] **编码段下沉 C++/WinRT DLL**（投影通、零拷贝编码不通）—— 通过 P/Invoke 暴露 `Encode_Init / Encode_SubmitTexture / Encode_Finish`。
- [ ] **工作器整体下沉 C++/WinRT**（探针无法在 C# 完成投影）—— 回退到 PRD #7 兜底。
