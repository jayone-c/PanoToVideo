# ADR 0002: 设备选择与回退策略

- 状态：**已实施**（P0-1 CPU 回退 + 设备探测真实化，2026-07-23）
- 日期：2026-07-23

## 背景
本机存在核显（AMD Radeon）+ 虚拟显示适配器 + RTX 4090 D 24GB。PRD 假设的"独显直接命中"不成立（开发规划 §0 差异1）。
仅凭 `DedicatedVideoMemory == 0` 判定虚拟适配器会误伤核显（核显也可能为 0）。

## 选择优先级（规划 §7，PRD #2）
1. 枚举 DXGI 适配器，先过滤 `DXGI_ADAPTER_FLAG_SOFTWARE`；**不得仅凭 `DedicatedVideoMemory == 0` 排除设备**。
2. 对候选适配器创建 D3D11 设备，并以该 Adapter LUID 枚举 MF H.264 硬件编码器及完成 NV12 纹理输入探测。
3. 命中"同 LUID 的 GPU 投影 + 硬件编码"者，优先独显，再按显存与探针性能排序；高级设置允许用户手动指定。
4. 无独显则使用通过同一探针的核显；再无则 CPU 回退。

## 回退触发（规划 §7，PRD #5）
- GPU 初始化失败、硬件编码器不可用 -> FFmpeg `v360` 投影 + 可用硬件编码（`h264_nvenc`/`h264_amf`/`h264_qsv`）或软件 `libx264`。
- **回退必须在 UI 与日志显式标注"CPU 回退"，不得悄悄走 CPU。**
- GPU 路径中"CPU 核心"参数不生效；仅在 CPU 回退时影响 `libx264 -threads`。

## 实现方案（P0-1，2026-07-23 已实施）

### Core 层纯逻辑决策（可单测）
- `IFallbackDecisionProbe` + `GpuAvailability`：GPU 可用性快照纯数据 record
  （HasGpu/HasH264Encoder/HasHevcEncoder/PreferredDeviceDescription/FallbackReason）。
- `FallbackDecider.Decide(gpu, resolvedPreset)`：纯逻辑 4 分支决策
  （无 GPU / 无 H.264 / H.265 可用 / H.265 不可用退 H.264），返回 `FallbackDecision`
  （Backend/ProjectionDeviceLabel/EncoderLabel/UsedCpuFallback/Reason）。

### Render 层探测实现
- `RenderFallbackDecisionProbe`：实现 `IFallbackDecisionProbe`，组合
  `CachedDeviceProbe`（GPU + H.264 编码器激活验证）+ `MfHevcEncoderProbe`（H.265 枚举）。
  静态缓存探测结果，批量任务复用。
- `FfmpegNvencExecutor`：GPU 路径，改用 `FfmpegCommandBuilder.BuildGpuNvenc`，
  上报真实设备（ProjectionDevice）与编码器（H.264/H.265 NVENC）。
- `FfmpegCpuFallbackExecutor`：CPU 回退路径，复用 Core `EquirectProjection`+`EquirectRenderer`
  软件投影 RGBA → FFmpeg stdin → `libx264 -threads {cpuCores}`，上报 CPU/libx264/UsedCpuFallback=true。

### App 层接入
- `MainViewModel.ExportAsync`：`RenderFallbackDecisionProbe.Probe()` → `PresetResolver.Resolve` →
  `FallbackDecider.Decide` → executorFactory 按决策选 `FfmpegNvencExecutor` 或 `FfmpegCpuFallbackExecutor`。
  UI 显式显示设备/编码器/回退原因（FallbackHint）。

## 探测结果（本机，2026-07-21 阶段1 + 2026-07-23 P0-1 验证）
| 适配器 | LUID | DedicatedVideoMemory | MF H.264 编码器 | ActivateObject 验证 | 选用 |
|---|---|---|---|---|---|
| NVIDIA RTX 4090 D（镜像1） | 0x017837 | 24 GB | NVENC | ✓ 通过 | **首选** |
| NVIDIA RTX 4090 D（镜像2） | 0x017837 | 24 GB | NVENC | ✓ 通过 | 备选（共享物理 GPU） |
| NVIDIA RTX 4090 D（镜像3） | 0x017837 | 24 GB | NVENC | ✓ 通过 | 备选（共享物理 GPU） |
| AMD Radeon 核显 | — | 0（共享） | AMF | ✓ 通过 | 核显备选 |
| WARP / 虚拟显示适配器 | — | — | 无 | ✗ 排除 | 不选 |

说明：3 个 NVIDIA 镜像适配器共享同一物理 4090D（同 LUID），都能 ActivateObject 通过。
`DeviceSelector.SelectPreferred` 按独显优先 + 显存排序命中首选。
HEVC 硬件编码器（NVENC HEVC）在本机可用，`PresetResolver` 体积优先保留 H.265 无退回。

## 测试覆盖
- `FallbackDecisionTests`：4 分支纯逻辑决策（无 GPU / 无 H.264 / H.265 可用 / H.265 不可用退 H.264）。
- `FfmpegCommandBuilderTests`：hevc_nvenc / h264_nvenc / libx264 -threads N / faststart / 码率一致。
- Render 层 GPU/FFmpeg 执行器无法纯单测，逻辑 correctness 靠 Core 命令构造器/决策类单测保证，
  执行器仅 build + 人工冒烟。
