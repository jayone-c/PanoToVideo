# ADR 0002: 设备选择与回退策略

- 状态：**待决**（阶段1 设备探测实现后填写）
- 日期：待定

## 背景
本机存在核显（AMD Radeon）+ 虚拟显示适配器 + RTX 4090 D 24GB。PRD 假设的"独显直接命中"不成立（开发规划 §0 差异1）。
仅凭 `DedicatedVideoMemory == 0` 判定虚拟适配器会误伤核显（核显也可能为 0）。

## 选择优先级（规划 §7，PRD #2）
1. 枚举 DXGI 适配器，先过滤 `DXGI_ADAPTER_FLAG_SOFTWARE`；**不得仅凭 `DedicatedVideoMemory == 0` 排除设备**。
2. 对候选适配器创建 D3D11 设备，并以该 Adapter LUID 枚举 MF H.264 硬件编码器及完成 NV12 纹理输入探测。
3. 命中"同 LUID 的 GPU 投影 + 硬件编码"者，优先独显，再按显存与探针性能排序；高级设置允许用户手动指定。
4. 无独显则使用通过同一探针的核显；再无则 CPU 回退。

## 回退触发（规划 §7，PRD #5）
- GPU 初始化失败、硬件编码器不可用 -> FFmpeg `v360` 投影 + 可用硬件编码（`h264_nvenc`/`h264_amf`/`h264_qsv`）或软件 `libx264`。
- **回退必须在 UI 与日志显式标注"CPU 回退"，不得悄悄走 CPU。**
- GPU 路径中"CPU 核心"参数不生效；仅在 CPU 回退时影响 `libx264 -threads`。
